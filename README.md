# My Favorite Series: Stranger Things

## About the Show
It's a sci-fi mystery set in the 1980s in a small town called Hawkins. A group of friends uncovers a secret lab and a parallel dimension known as the Upside Down.

### Why I Love It
- 🎭 Great acting and characters
- 🕵️‍♂️ Interesting mysteries and secrets
- 🎵 Amazing 80s music and style
- 💖 Shows the power of friendship

## Main Characters
| Character | Description |
